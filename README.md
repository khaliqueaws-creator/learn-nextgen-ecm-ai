# Learn NextGen ECM AI

A hands-on learning repository for building AI capabilities around a next-generation Enterprise Content Management platform.

This repository supports the Django/OpenShift document-management application and captures learning notes, architecture decisions, runbooks, prompts, and proof-of-concept plans.

## Learning Focus

- AI fundamentals
- Embeddings
- PostgreSQL and pgvector
- Semantic search
- Ollama local LLMs
- Amazon Bedrock
- Google Gemini
- Retrieval-Augmented Generation
- AI metadata extraction
- AI agents
- OpenShift AI deployment patterns

## Repository Structure

```text
ai-learning/   Day-wise AI learning notes
architecture/  Current and target architecture
 decisions/    Architecture decision records
runbooks/      Operational runbooks
prompts/       Codex, RAG, Bedrock, and Gemini prompts
poc/           Proof-of-concept experiments
```

## Goal

Use this repository as a developer and architect notebook while evolving the document-management application into an AI-powered knowledge platform.
