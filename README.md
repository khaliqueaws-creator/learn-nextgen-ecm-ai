# Learn NextGen ECM AI

A hands-on learning repository for building AI capabilities around a next-generation Enterprise Content Management platform.

This repository supports the Django/OpenShift document-management application and captures learning notes, architecture decisions, runbooks, prompts, and proof-of-concept plans.

## Technology Focus

Core Platform:
- Django
- OpenShift
- PostgreSQL
- OpenSearch
- OCR
- AWS Bedrock

AI Focus:
- AI fundamentals
- Embeddings
- Semantic Search
- OpenSearch Vector Search
- Retrieval-Augmented Generation (RAG)
- AI Metadata Extraction
- AI Agents
- Enterprise Content Management Architecture
